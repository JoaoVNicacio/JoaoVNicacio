## About Me

Hello, I'm João Victor Nicácio, a Software Engineer from Pernambuco, Brazil.

I work primarily with **Chromium WebUI and backend systems**, building software with **C++, TypeScript, C#, .NET, and Node.js**.

My experience includes **Chromium WebUI, Mojo, distributed systems, microservices, REST APIs, messaging, databases, and software architecture**. I also have experience with Windows application development using **WinUI, WPF, UWP, and MVVM**.

I enjoy understanding how systems work as a whole, exploring technical trade-offs, and turning requirements into practical solutions. I also contribute to **technical research, documentation, onboarding, knowledge sharing, and engineering practices**.
